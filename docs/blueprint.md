# **App Name**: DocFlow

## Core Features:

- PDF Dashboard & Preview: A user-friendly dashboard to select and upload multiple PDF files, displaying interactive visual thumbnails for easy document overview.
- Merge PDFs: Combine several selected PDF documents into a single, cohesive PDF file.
- Page Rotation: Rotate individual pages within any loaded PDF to correct misaligned scans or orientations.
- OCR Text Extraction Tool: Extract textual content from PDF pages, including using Optical Character Recognition (OCR) as a tool to capture text from images or scanned documents.
- Page Deletion: Select and remove one or more unwanted pages from a PDF document, ideal for duplicate or blank pages.
- Page Reordering: Intuitive drag-and-drop interface to easily rearrange the sequence of pages within a PDF.
- Export Modified PDF: Save all changes and edits made to the document as a brand new PDF file, preserving the original.

## Style Guidelines:

- Primary color: Deep Indigo (#481CA8). This rich, digital purple hue embodies innovation and professionalism, grounding the interface.
- Background color: Very Light Lavender (#F3F0FA). A soft, airy off-white tint provides a clean, open canvas, ensuring clarity and enhancing readability of documents.
- Accent color: Bright Sapphire Blue (#1A70FF). A vibrant, clean blue chosen for its energizing yet reliable feel, perfect for calls to action and highlighting interactive elements.
- Headline font: 'Space Grotesk' (sans-serif) for its modern, slightly technical flair, lending a contemporary edge to titles and main headings.
- Body font: 'Inter' (sans-serif) for its high legibility and neutral yet modern appearance, ideal for comfortable reading of document text and interface labels.
- Utilize a consistent set of clean, minimalist line icons. Each icon should be clearly recognizable and directly represent its associated function (e.g., upload, merge, rotate, delete, save) for quick comprehension.
- Implement a clear, multi-panel layout with a prominent central canvas for PDF previews and manipulations, complemented by an accessible sidebar or toolbar for features. Ensure responsive design for seamless adaptability across devices.
- Incorporate subtle, quick, and purposeful animations for interactions like file uploads, page transitions, and tool activation. These micro-interactions should enhance responsiveness and provide immediate visual feedback without slowing down the user experience.
